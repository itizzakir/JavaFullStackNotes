# Java Full Stack Notes

This Vite + React project is now prepared for three note modules:

- JavaScript Notes: `public/javascript-notes.html`
- HTML Notes: `public/html-notes.html`
- Java Notes: `public/java-notes.html`

## Run

```bash
npm install
npm run dev
```

## Build

```bash
npm run build
```

## How to add new notes later

1. Share your new notes topic.
2. I will update the matching file in `public/`.
3. It will appear automatically in the module switcher UI.
